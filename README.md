# Dune & Pearl Experiences

A fictional Qatari leisure and tourism organisation used as the central vocational case study for Pearson BTEC International Level 3 Information Technology.

## Live site

https://dune-pearl-experiences.netlify.app/

## Purpose

The site gives students a consistent organisation through which to explore IT infrastructure, stakeholders, data, connectivity, security, organisational policy and IT management.

## Deployment

The project is a static website designed for continuous deployment through Netlify.

## Assessment boundary

This public repository contains only student-facing company information. Protected Pearson assignments, teacher answers and assessment records must not be added here.
