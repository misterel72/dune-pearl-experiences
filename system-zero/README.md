# Dune & Pearl: System Zero

Student-facing cooperative escape-room activity for BTEC International Level 3 IT Unit 1, lessons L01-L07.

## Student route

`/system-zero/`

Students work in teams of three and select different roles: Doha Operations Centre, Pearl Marina Hub and Dune Desert Camp. Progress is stored locally in the browser.

## Curriculum focus

- understand the client and organisation
- separate facts, assumptions, constraints and missing evidence
- build evidence-based reasoning
- convert proposed solutions into requirements
- apply case evidence across business functions
- ask neutral questions
- review and improve recommendations

This is formative teaching and practice. It is not a Pearson Set Assignment.
